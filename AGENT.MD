3. Hard Engineering Rules & Guardrails3.1. SI Unit Standardization (Mandatory)Internal Core Rule: Every variable inside src/physics, src/weather, src/spatial, and src/core MUST strictly use SI units:Speed (STW, SOG, TWS, Current): meters per second (m/s) (f64).Angles (TWA, COG, HDG, Heel): radians (rad) (f64), normalized to $[0, 2\pi)$ for bearings/headings and $[-\pi, \pi]$ for relative angles (TWA).Distance & Depth (UKC, Squat, Draft, Wave Height): meters (m) (f64).Geographic Coordinates: WGS84 Decimal Degrees (lat $\in [-90.0, 90.0]$, lon $\in [-180.0, 180.0]$) (f64).Time: UTC Unix Timestamp in seconds (i64); deltas $\Delta t$ in seconds (f64).Boundary Conversion Rule: Conversion between nautical units (knots, degrees, nautical miles, liters/hour) and SI units is permitted ONLY in src/api/ and file parsers (src/physics/polar.rs). Use explicit newtype wrappers (e.g., struct Knots(f64); struct MetersPerSecond(f64);) to prevent unit mix-ups at compile time.3.2. Memory & Performance GuardrailsZero Heap Allocations in Hot Loop: Inside calculate_isochrones inner candidate evaluation loop, dynamic heap allocations (Vec::new(), String::clone(), Box::new()) are FORBIDDEN. Pre-allocate scratch buffers per worker thread or use stack arrays.Zero-Copy Weather Access: Never load entire GRIB2 files via eccodes inside the Rust worker. Read pre-chunked Zarr arrays ([lat, lon, time]) via memmap2 so OS page cache handles memory sharing across worker threads.Anti-Patterns (STRICTLY FORBIDDEN):NEVER interpolate wind or current direction angles directly (causes $350^\circ + 10^\circ \rightarrow 180^\circ$ wrap-around bug). ALWAYS interpolate orthogonal components $U$ and $V$ separately, then compute atan2.NEVER use flat Euclidean geometry ($\Delta x, \Delta y$) for distance or projection. ALWAYS use spherical/ellipsoidal geodesy with antimeridian normalization.NEVER block the tokio async executor thread with CPU-bound routing loops. Always dispatch routing computations onto a dedicated rayon thread pool or tokio::task::spawn_blocking.4. Core Domain Specifications (Math, Algorithms & Contracts)4.1. Mathematical & Physical EquationsAntimeridian Longitude Normalization:$$\Delta\lambda = ((\lambda_2 - \lambda_1 + \pi) \bmod 2\pi) - \pi$$(Ensure positive modulo in Rust: ((dlon + PI).rem_euclid(2.0 * PI)) - PI).Trilinear 4D Weather Interpolation:Given grid cell indices $(i, j, k)$ and fractional offsets $\alpha_x, \alpha_y, \alpha_t \in [0, 1]$:Perform bilinear interpolation on $U$ and $V$ at $t_k$ and $t_{k+1}$.Perform linear interpolation between $t_k$ and $t_{k+1}$ using $\alpha_t$.Reconstruct wind/current vector magnitude and meteorological/oceanographic angle via hypot(u, v) and atan2.True Wind & Apparent Wind / Vector Kinematics:Given boat velocity vector $\vec{V}_{boat}$ (from STW and HDG), leeway vector $\vec{V}_{leeway}$, and ocean current vector $\vec{V}_{curr} = (u_{curr}, v_{curr})$:$$\vec{V}_{SOG} = \vec{V}_{STW}(\text{HDG}) + \vec{V}_{Leeway} + \vec{V}_{curr}$$$$\text{SOG} = \|\vec{V}_{SOG}\|_2, \quad \text{COG} = \text{atan2}(V_{SOG, x}, V_{SOG, y}) \bmod 2\pi$$Classical Leeway magnitude:$$\|\vec{V}_{Leeway}\| = K_{leeway} \cdot \frac{\phi_{heel}}{(\text{STW})^2}$$applied perpendicular to HDG away from the windward side. (If STW < 0.25 m/s, clamp denominator to 0.25 to prevent division-by-zero singularity).Low-Wind VPP Quadratic Stall Scaling:When $\text{TWS} < \text{TWS}_{min\_polar}$:$$\text{STW}(\text{TWA}, \text{TWS}) = \text{STW}(\text{TWA}, \text{TWS}_{min\_polar}) \cdot \left(\frac{\text{TWS}}{\text{TWS}_{min\_polar}}\right)^2$$No-Sail Zone Tapering Ramp:For $|\text{TWA}| < \text{TWA}_{beat\_min}$ (or downwind dead-run $|\text{TWA}| > \text{TWA}_{gybe\_max}$), apply a smooth/linear tapering multiplier $\gamma \in [0, 1]$ down to 0.0 at $|\text{TWA}| \le 0.75 \cdot \text{TWA}_{beat\_min}$ to eliminate direct upwind nodes without hard discontinuities.Dynamic Under-Keel Clearance (UKC) & Squat (Barrass Formula):Convert $\text{STW}$ to knots ($V_k = \text{STW} \cdot 1.943844$):$$\text{Squat}_{\text{meters}} = \frac{C_b \cdot V_k^2}{100.0}$$$$\text{Draft}_{heel} = \text{Draft}_{static} \cdot \cos(\phi_{heel}) + \frac{B}{2} \cdot \sin(|\phi_{heel}|)$$(Note: If beam $B$ or $\phi_{heel}$ is absent in vessel profile, escalate via Q-XXX or fallback to $\text{Draft}_{heel} = \text{Draft}_{static}$).Prune edge if:$$\text{UKC} = \text{Depth}_{tide\_adjusted} - (\text{Draft}_{heel} + \text{Squat}_{\text{meters}}) \le \text{UKC}_{safety\_margin}$$Multi-Objective Edge Cost & Penalties:$$\text{Cost}_{edge} = \Delta t + P_{tack} \cdot \mathbb{I}(\text{tack\_changed}) + P_{gybe} \cdot \mathbb{I}(\text{gybe\_changed}) + P_{sail} \cdot \mathbb{I}(\text{sail\_changed}) + w_{fuel} \cdot \Delta\text{Fuel} + w_{wave} \cdot \max(0, H_s - H_{comfort})$$4.2. Routing & Spatial Collision AlgorithmsTwo-Phase Spatial Collision Detection (src/spatial/rtree_index.rs)Broad-Phase: Construct an Axis-Aligned Bounding Box (MBR) around geodesic segment $\overline{P_1 P_2}$ (accounting for antimeridian split if $|\lambda_2 - \lambda_1| > \pi$). Query rstar::RTree::locate_in_envelope_intersecting(&mbr).Narrow-Phase: For each candidate polygon (coastline buffered by $50\text{ m}$ or active NoGoZone), run exact segment-polygon intersection (geo::Intersects). Return true immediately on first hit.Modified Isochrone Propagation (src/core/isochrone.rs)Initialize active_front with start_node ($t = t_0$).Loop while target is not within capture radius ($R_{capture} = \text{SOG}_{max} \cdot \Delta t$) of any node in active_front:For each node in active_front:Query WeatherGrid4D at (node.lat, node.lon, node.time). If time exceeds forecast horizon, trigger ClimatologyFallback and set warning flag.Iterate over candidate headings $\text{HDG} \in [0, 2\pi)$ with step $\Delta\theta$ (e.g., $2^\circ$ or $5^\circ$):Compute TWA, TWS, STW, wave resistance reduction, Leeway, and vector-summed SOG, COG.Check weather safety limits (TWS > max_tws or H_s > max_wave_height) $\rightarrow$ prune if violated.Check MotorSailing: if SOG < min_motoring_sog and fuel_remaining >= fuel_rate * dt, override SOG = motoring_sog, COG = HDG, deduct fuel, set is_motoring = true.Project (next_lat, next_lon) along COG by distance $\text{SOG} \cdot \Delta t$.Run spatial_index.intersects_obstacle(node.pos, next_pos) and ukc_check $\rightarrow$ prune if violated.Compute cumulative cost including tack/gybe/sail-change penalties.Bearing Bucket Pruning: Divide azimuths from start_node (or toward target) into $N$ angular sectors (e.g., $1^\circ$ buckets = 360 buckets). Within each bucket, retain ONLY the candidate node maximizing projected progress toward target (Velocity Made Good on Course / minimum heuristic total time $t_{elapsed} + \text{dist}(P, \text{target}) / V_{max}$).Set active_front = pruned_candidates.Connect final front nodes within $R_{capture}$ to target, select minimum total cost node, and backtrack parent pointers to reconstruct Vec<Waypoint>.4.3.
