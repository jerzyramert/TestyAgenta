# Deferred Features

## Wave added resistance

Wave added resistance is intentionally excluded from the MVP. No wave-resistance
reduction is applied to VPP speed. Reconsider this feature in a future release
after selecting and validating the ISO 15016/Kwon method, required hull inputs,
and the mapping from added resistance to STW reduction.

## Tide-adjusted bathymetry

The MVP uses chart depth without tide adjustment. Add a future mechanism that
provides tide-adjusted depth at each route position and time.
